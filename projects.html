FINAL YEAR PROJECT

e-Sign: Sign Language Learning System

Development of a Sign Language Learning System to Support Communication for Individuals with Hearing and Speech Disabilities

This project focuses on developing a sign language learning system to help individuals with little or no knowledge of sign language learn basic communication. The system provides visual learning materials covering alphabets and everyday words, together with a hand gesture recognition approach to support the learning process.
